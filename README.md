# Customer Churn Analysis Dashboard

A dynamic and interactive Power BI dashboard designed to analyze customer churn patterns and identify key factors influencing customer retention.

## Short Description

The Customer Churn Analysis Dashboard helps businesses understand why customers leave by analyzing patterns across contract types, tenure, support interactions, and payment behavior. Built using a dataset of over 440,000 customer records, it enables data-driven decision-making to improve retention strategies.

## Tech Stack

The dashboard was built using:

* 📊 **Power BI Desktop** – Main data visualization platform
* 📂 **Power Query** – Data transformation and cleaning
* 📂 **DAX (Data Analysis Expressions)** – Used for calculated measures like churn rate
* 📂 **Data Modeling** – Relationships between customer attributes
* 📁 **File Formats** – `.pbix` / `.pbit` for development, `.png` for dashboard preview

## Data Source

* Dataset: https://www.kaggle.com/datasets/muhammadshahidazeem/customer-churn-dataset

## Key Features of Dataset:

* Customer ID
* Age & Gender
* Contract Length
* Tenure
* Support Calls
* Payment Delay
* Subscription Type
* Churn (0 = Stayed, 1 = Churned)

## Features / Highlights

## Business Problem

Customer churn directly impacts business revenue and growth.
Organizations often struggle to identify:

* Which customers are most likely to churn
* How customer behavior influences retention
* What operational factors increase churn risk

### 🎯 Goal of the Dashboard

To build an interactive dashboard that:

* Identifies key churn drivers
* Helps improve customer retention strategies
* Supports data-driven decision-making

---

### 📈 Walkthrough of Key Visuals

#### 🔹 KPI Cards (Top Section)

* Total Customers
* Churn Customers
* Churn Rate

#### 🔹 Churn by Contract Length

Compares churn across:

* Monthly
* Quarterly
* Annual

Insight: Customers with short-term contracts (monthly) show higher churn

#### 🔹 Churn by Tenure Group

Customer segmentation:

* 0–1 Year
* 1–3 Years
* 3+ Years

Insight: New customers (0–1 year) have the highest churn rate

#### 🔹 Churn by Support Calls

Grouped into:

* 0 Calls
* 1–3 Calls
* 4–6 Calls
* 7+ Calls

Insight: Higher number of support calls indicates dissatisfaction → higher churn

---

#### 🔹 Churn by Payment Delay

Categories:

* No Delay
* 1–2 Days
* 3–5 Days
* 6+ Days

Insight: Customers with frequent payment delays are more likely to churn

---

#### 🔹 Filters / Slicers

* Gender
* Age Group
* Subscription Type

Enables dynamic filtering and deeper analysis

---

## Business Impact & Insights

* 📉 Customers with **6+ payment delays** show the highest churn
* 📞 Customers with **7+ support calls** are high-risk users
* ⏳ Customers with **0–1 year tenure churn the most**
* 📆 Monthly contract users are more likely to churn compared to long-term contracts
